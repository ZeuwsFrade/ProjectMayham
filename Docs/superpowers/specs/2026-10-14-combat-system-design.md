# Боевая система и ИИ врагов — дизайн и справка

Спринт: ближний бой, вес удара, оружие как данные, смерть игрока, база ИИ, враг «Доходяга».

## Управление

| Действие | Ввод |
|---|---|
| Поднять оружие | ПКМ (держать) — медленнее ход, уже конус зрения, нельзя бегать |
| Удар | ЛКМ при поднятом оружии: короткое нажатие — лёгкий удар по дуге |
| Тяжёлый удар | ЛКМ зажать до полной зарядки (полоска в HUD становится жёлтой), отпустить |
| Взять оружие в руки | как любой предмет: инвентарь → ПКМ по предмету; `H` — убрать |

Удар тратит выносливость в момент замаха (при отпускании кнопки): пока ЛКМ зажата, ничего не списывается. Не хватает на
тяжёлый — бьёт обычным; не хватает на обычный — удара нет («Не хватает сил»). Каждый попавший удар изнашивает оружие
(тяжёлый — вдвое сильнее); на нуле оружие ломается и исчезает из рук. Удар по врагу в момент его замаха прерывает замах:
враг теряет равновесие (стаггер).

## Устройство

```
Scripts/Combat   IDamageable, DamageInfo, Health, WeaponDefinition, WeaponWear, MeleeCombat, MeleeVisual,
                 HitStop, CameraShake, CombatEvents, Noise, PlayerNoise, PlayerDeath, HitFlash, CombatRuntime
Scripts/AI       EnemyDefinition, EnemyAI (автомат), EnemyMotor (ноги), NavGrid (A*), AlertDirector,
                 Swarm, Dokhodyaga, EnemySpawner
Scripts/UI       CombatHUD
Editor/Combat    CombatSetup (ассеты и подключение сцены), CombatSelfTest
```

* **Урон** идёт только через `IDamageable.TakeDamage(in DamageInfo)`. `DamageInfo` несёт урон, точку, направление,
  отбрасывание, время стаггера, оружие и атакующего. `Team` (Player / Enemy / Neutral) не даёт врагам бить друг друга.
  `PlayerStats` реализует `IDamageable`, враги — через `Health`.
* **Оружие** — `WeaponDefinition : ItemDefinition`: это предмет (инвентарь, торговец, база предметов, сохранение работают
  как раньше), плюс урон, дальность, дуга, скорости, стоимость выносливости, вес удара, прочность, шум. Тестовые: `Pipe`
  (труба — лёгкая и быстрая) и `Sledgehammer` (кувалда — тяжёлая и медленная), `Assets/Data/Items/Weapons/`.
* **Износ** хранится по виду оружия (`WeaponWear`, в `SaveData.weaponWear`): инвентарь знает предметы только по
  определению, поэтому две трубы делят одну прочность, а новая труба после поломки целая. Смерть в рейде забывает износ
  потерянного оружия, оружие на складе его сохраняет.
* **Вес удара.** `HitStop` — короткая заморозка игры через `ModalState.Slowdown`: пауза от окна всегда сильнее
  заморозки, и они не отменяют друг друга. `CameraShake` — тряска «травмой» по реальному времени; смещение снимается в
  начале кадра и накладывается в конце, поэтому не спорит с `CameraFollow`. Стаггер и отбрасывание приходят во врага через
  `DamageInfo`.
* **Смерть игрока.** `PlayerStats.Died` — в момент смерти. `PlayerDeath` отнимает управление, играет заглушку
  (падает на бок, темнеет), затем поднимает `PlayerDeath.OnDied`; `RaidController` слушает именно его (без `PlayerDeath`
  в сцене — старое поведение, по `Died`).

## События для звука и музыки

Подписка без ссылок на игрока и врагов, обработчики сбрасываются при каждом запуске игры.

| Событие (`CombatEvents`) | Когда |
|---|---|
| `SwingStarted(SwingEvent)` | замах игрока, начало замаха врага (`Weapon == null`) |
| `HitLanded(HitEvent)` | удар попал (в том числе по игроку) |
| `SwingMissed(SwingEvent)` | удар прошёл мимо |
| `WeaponBroken(WeaponDefinition)` | оружие сломалось |
| `ActorDied(GameObject)` | умер кто угодно, игрок тоже |
| `EnemyShouted(GameObject, Vector2)` | доходяга позвал стаю |
| `AlertChanged(AlertLevel)` | общий уровень тревоги: `Calm` / `Suspicious` / `Alarm` — для музыки |

Подъём тревоги приходит сразу, спад — через 2,5 с (с подозрения) и 5 с (с тревоги), чтобы музыка не дёргалась.
`Noise.Emit` — шум для врагов (шаги, замахи, удары); это не звук для игрока.

## ИИ

**Решение: свой A* по сетке, без NavMeshPlus.** Уровень — тор (`WrapWorld`): путь должен идти через шов, а запечённый
NavMesh про шов ничего не знает. Уровень собран из тайлов — сетка его родная форма. Баррикады двигают и разбирают —
сетка переопределяется на лету (по 250 клеток в кадр). Пакета не нужно.

* `NavGrid` — клетки 1×1, занятость берётся с физики (`Obstacle`, `Furniture`, `Window`), A* по 8 соседям без срезания
  углов, шов учтён, путь выпрямляется. Точки пути отдаются в координатах того, кто спросил: за швом они просто
  продолжаются. Бюджет — 4 поиска в кадр. Построение уровня 204×204 — около 17 мс, поиск — в среднем 1,6 мс.
* `EnemyAI` — автомат: **Patrol → Suspicious → Chase → Attack → Stagger** (+ Dead). Видит (дальность, угол, стены) и
  слышит (`Noise`, стена глушит вдвое). Осведомлённость копится, пока враг видит игрока. Тревога каждого врага уходит в
  `AlertDirector`.
* `EnemyDefinition` — все числа врага. Новый враг — это новый ассет, а непохожее поведение — наследник `EnemyAI`
  с переопределением `ChaseDestination` / `OnPlayerNoticed` / `OnStateEntered`.
* **Доходяга** (`Dokhodyaga`): один слаб (40 здоровья, скорость 2,7 против 3,5 шага игрока, 6 урона примерно раз в 2 с,
  легко выбивается из атаки). Сила — в толпе: нашедший игрока кричит, стая приходит на крик; вблизи доходяги не стоят в очереди,
  а расходятся по кольцу вокруг игрока (`Swarm`). Пятеро в открытом месте убивают игрока за секунд десять — это задумано.
* `EnemySpawner` расставляет стаи при старте рейда: свободные клетки не ближе 22 до игрока, до которых можно дойти.

* `Mayham/Combat/Give test weapons (play mode)`, `Spawn a pack near the player (play mode)` — для проверки.
* `Mayham/Combat/Run Self-Test` — 101 проверка без Play Mode (ассеты, износ, здоровье, тревога, пауза и заморозка, поиск
  пути на сетках в памяти, в том числе через шов).

## Известные ограничения

* Оружие в предметах — без своего состояния: износ делят одинаковые предметы (см. выше), продажа торговцу и
  выкуп обратно сбрасывать его не умеют.
* Торговец Тайлер в существующем сохранении не получит оружия: запас торговца лежит в `save.json`.
* Баланс (урон, здоровье, цены) — первое приближение, всё в ассетах `Weapons/` и `Enemies/`.
* Звука и анимации нет: события опубликованы, на них ничего не подписано; смерть и атаки — заглушки.
