# Детализированные версии врагов

Оба игровых PNG в Assets/Sprites/Combat теперь имеют размер 256×256. Они подготовлены из подробных исходников предыдущей генерации (*-Redrawn-Source.png в соседней папке 2026-10-29-Combat), а не увеличены из маленьких 16×16 и 22×22. Новая генерация не выполнялась. Использовано уменьшение исходников методом nearest-neighbor для сохранения пиксельного стиля.

Настройки импорта применены через Inspector открытого Unity 6000.3.10f1:

| Спрайт | Было | Стало | Размер холста в мире |
|---|---|---|---|
| Dokhodyaga | 16×16, 16 PPU | 256×256, 256 PPU | 1×1 |
| Justice | 22×22, 16 PPU | 256×256, 186.18182 PPU | приблизительно 1.375×1.375 |

Сохранены Sprite Single, центральный pivot, Point, прозрачность, отсутствие сжатия, исходные GUID. Unity успешно импортировал оба PNG; проверены Inspector, вид сцены CombatTest, размеры PNG и PPU в сохранённых настройках. Play Mode не запускался. Контуры на прозрачном фоне могут немного отличаться от прежних из-за выборки при уменьшении; размер холста в игровых единицах сохранён.

В этой папке сохранены предыдущие маленькие PNG и их .meta для восстановления. Масштабы объектов и коллайдеры не менялись.
